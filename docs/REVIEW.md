## 2. 合规边界（文档未覆盖的部分）

### 2.1 第三方价格接口

`https://price.maenohou.com/robots.txt`：`User-agent: *` → `Disallow: /api/`。现有扩展每次查价都在访问该路径。自用无碍，但公开发布会把"批量调用被禁接口"写进公开代码。

**已决策**：历史数据一次性导入本站数据库，运行时不再调用第三方；导入器独立成 `server/import_history.py`，与线上服务解耦。

### 2.2 DLsite 侧

`https://www.dlsite.com/robots.txt` 实测：`Crawl-delay: 10`；`/*/mypage`、`/*/cart`、`/*search/result`、`/*work/image/sample/` 均 `Disallow`。

| 约束 | 对设计的强制影响 |
| --- | --- |
| `/*/mypage` 禁抓 | 持券接口只能在用户浏览器内调用，**服务端永不触碰** |
| `/*/cart` 禁抓 | 购物车对比功能只能存在于扩展/脚本内，网站不提供 |
| `Crawl-delay: 10` | 服务端刷新预算上限 ≈ 8,640 次/天，决定"入库多少作品、多久刷新一轮" |
| `/*work/image/sample/` 禁抓 | 封面图只能取联盟后台素材，不能自行抓取 |

[利用規約](https://www.dlsite.com/soft/user/regulations) 禁止行為条项另含：

- 「BOT、チートツール、その他の技術的手段を利用して本サービスを不正に操作する行為」
- 「当社が事前に許諾しない本サービス上での宣伝、広告、勧誘、または営業行為」

后者意味着**在扩展内展示联盟链接属于默认禁止**，必须先取得书面许可。已列入 M0 并行事项。
